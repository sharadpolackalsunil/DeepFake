# TMLR submission checklist

Rules from jmlr.org/tmlr (submissions, author-guide, editorial-policies, acceptance-criteria, ethics, faq), checked 2026-11-15.

## Format
- [x] Unmodified TMLR style files (byte-identical to JmlrOrg/tmlr-style-file); `\usepackage{tmlr}` without options (anonymous)
- [x] No hard page limit; main body over 12 pages slows review. Main body ends on p. 10 (references start p. 11)
- [x] Appendix after the references
- [x] LLM-use footnote on the first page
- [x] All tables generated by `tools/paper_tables.py` from `results/tables/`

## Anonymity (double blind)
- [x] No names, institutions or repo URLs in the PDF; PDF metadata blank
- [ ] Supplementary ZIP (<= 100 MB, PDF or ZIP only) built from a fresh export, NOT the git history; strip author names from `docs/decisions.md` sign-off lines and `docs/tmlr_checklist.md`
- [ ] Do not link an arXiv preprint from the review copy; if posting one, use `\usepackage[preprint]{tmlr}`

## Claims (acceptance criterion 1)
- [x] Registered verdicts reported as registered (H1/H2/H4a undetermined, H3a/H3b/H5/H6/H8 falsified, H7b/c-v2 supported)
- [x] Post-hoc analyses labelled as such (H8 reseed check, 3 SE reading)
- [ ] Complete outstanding sign-offs in `docs/decisions.md` (D18 option (b) date/initials; D19 freeze sign-off) truthfully, before submission

## Ethics
- [x] Broader impact statement (false assurance under non-exchangeability; dual use; dataset terms; no new human data)

## OpenReview
- [ ] All authors have complete, active OpenReview profiles; author list final (cannot change later)
- [ ] 3-5 Action Editor suggestions ready (requested by email after submission)
- [ ] Conflicts entered honestly
- [ ] No parallel submission to another archival venue
